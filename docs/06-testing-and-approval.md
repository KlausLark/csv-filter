# 6. Проверка готовности и согласование

## 6.1. Критерии готовности

MVP считается готовым, когда:
- корректный CSV-файл загружается и отображается;
- заголовки столбцов отображаются правильно;
- условие «Цена больше 1000» возвращает ожидаемые строки;
- текстовый оператор «содержит» работает согласно выбранному правилу регистра;
- пустые и нечисловые значения не приводят к аварийному завершению;
- некорректный или пустой файл обрабатывается понятным сообщением;
- сброс фильтра возвращает исходные строки;
- экспорт содержит заголовки и только отфильтрованные строки;
- исходный файл остаётся неизменным;
- логика фильтрации покрыта автоматизированными тестами;
- документация доступна в репозитории.

## 6.2. Минимальные тестовые сценарии

| № | Сценарий | Ожидаемый результат |
|---:|---|---|
| 1 | Открытие корректного CSV | Заголовки и строки отображаются |
| 2 | Фильтр «Цена больше 1000» | Остаются строки с ценой больше 1000 |
| 3 | Текстовый фильтр «содержит» | Остаются строки с заданным фрагментом |
| 4 | Пустые ячейки в числовом столбце | Программа не завершается аварийно |
| 5 | Пустой файл | Отображается понятное сообщение |
| 6 | Ошибка доступа к выходному файлу | Отображается сообщение об ошибке сохранения |
| 7 | Сброс фильтра | Возвращаются все исходные строки |
| 8 | Экспорт результата | Новый файл содержит заголовки и подходящие строки |

## 6.3. Открытые вопросы

До реализации нужно подтвердить проектные предположения:
1. Основная платформа - Windows.
2. Заголовки находятся в первой строке CSV.
3. В MVP применяется одно условие фильтрации за раз.
4. Основная кодировка - UTF-8.
5. Целевой тестовый объём - до 10 000 строк и 20 столбцов. Производительность проверяется на согласованном компьютере.
6. Результат сохраняется в новый файл, исходник автоматически не перезаписывается.

Эти пункты являются проектными предположениями, а не требованиями, прямо заданными в теме варианта.
