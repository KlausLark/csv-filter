# 1. Краткое резюме, видение и границы проекта

## 1.1. Краткое резюме (Executive Summary)

CSV-фильтр - настольная утилита для загрузки табличных данных из CSV-файлов, отбора строк по заданному пользователем условию и сохранения результата в новый файл. Проект предназначен для пользователей, которым нужно быстро обработать таблицу без ручного поиска строк и без обязательного использования электронных таблиц.

В минимальную версию продукта (MVP) входят открытие CSV-файла, отображение заголовков и данных, настройка одного условия фильтрации, просмотр результата и экспорт в отдельный CSV-файл. Приложение работает локально: пользовательские файлы не отправляются на внешний сервер.

Для учебной реализации предлагаются Python и Tkinter. Для чтения и записи CSV используется стандартный модуль csv. Такой стек снижает сложность установки и не требует платной инфраструктуры.

Этот документ является проектным предложением (Project Charter & Development Plan) для согласования объёма работ, требований, архитектуры, предварительной оценки и рисков до начала реализации.

## 1.2. Проблема и обоснование

При работе с таблицами пользователю часто требуется выбрать записи, удовлетворяющие определённому условию. Например, найти товары дороже 1000 рублей, заказы со статусом «В обработке» или строки, содержащие заданное слово. Ручная обработка занимает время и повышает вероятность ошибки.

CSV-фильтр автоматизирует этот процесс. Пользователь задаёт условие, программа проверяет строки и позволяет сохранить подходящие записи отдельно.

## 1.3. Цель, бизнес-показатели и критерии успеха

**Цель:** разработать простую локальную утилиту, которая загружает CSV, фильтрует строки по одному условию и экспортирует результат без изменения исходного файла.

**Предлагаемые KPI для проверки MVP:**

| Показатель | Целевое значение | Как проверить |
|---|---|---|
| Время фильтрации | Не более 2 секунд для файла до 10 000 строк и 20 столбцов | Измерить время на согласованном тестовом компьютере |
| Корректность результата | 100% совпадение с ожидаемыми результатами на контрольном наборе тестов | Сравнить результат программы с заранее подготовленными ожидаемыми строками |
| Сохранность исходных данных | Исходный файл не изменяется при фильтрации и экспорте | Сравнить исходный файл до и после теста |
| Успешность основного сценария | Все обязательные пользовательские сценарии проходят приёмочные проверки | Выполнить чек-лист из разделов 2 и 6 |

Дополнительная бизнес-гипотеза: при регулярной обработке таблиц приложение должно сокращать время ручного отбора строк. До реализации процент экономии времени не считается подтверждённым. Его можно измерить отдельно, сравнив время ручного и автоматизированного выполнения одной задачи на одинаковом тестовом файле.

## 1.4. Участники проекта и их цели (Actors)

| Участник | Потребность и цель |
|---|---|
| Пользователь-оператор | Открыть таблицу, задать условие, быстро увидеть нужные строки и сохранить результат |
| Начинающий пользователь | Выполнить фильтрацию без написания кода и без сложной настройки |
| Разработчик / сопровождающий | Поддерживать понятную структуру кода, проверять корректность фильтрации и исправлять ошибки |
| Преподаватель / принимающая сторона | Проверить соответствие результата заданию по формальным критериям приёмки |

Авторизация и отдельная роль администратора в MVP не нужны, поскольку приложение рассчитано на локальную работу одного пользователя.

## 1.5. Границы проекта

### Входит в MVP (In Scope)

- открытие CSV-файла через диалог выбора файла;
- чтение первой строки как заголовков столбцов;
- отображение данных в табличном виде;
- выбор одного столбца и одного условия фильтрации;
- операторы «равно», «не равно», «больше», «меньше», «содержит»;
- отображение количества найденных строк;
- сброс фильтра и возврат к исходному набору данных;
- экспорт результата в новый CSV-файл;
- обработка типичных ошибок чтения и сохранения;
- базовые автоматизированные тесты логики фильтрации.

### Не входит в MVP (Out of Scope)

- редактирование ячеек и сохранение изменений в исходной таблице;
- одновременное применение нескольких условий AND/OR;
- сортировка и построение диаграмм;
- импорт Excel (.xlsx) и других форматов;
- подключение к базам данных и внешним API;
- учётные записи, облачная синхронизация и многопользовательская работа;
- обработка произвольно больших файлов без ограничений по памяти;
- создание установщика и автоматическое обновление приложения.

Новые возможности могут быть добавлены в следующих версиях после завершения обязательного MVP и отдельного согласования.

## 1.6. Допущения и ограничения

- CSV-файл содержит строку заголовков.
- На первом этапе приложение обрабатывает файл целиком в памяти.
- Основная кодировка - UTF-8.
- Поддерживаются запятая и точка с запятой как разделители; при неоднозначности пользователь должен иметь возможность выбрать разделитель.
- Числовые сравнения выполняются только тогда, когда значение выбранной ячейки можно корректно преобразовать в число.
- Основной сценарий ориентирован на обычный настольный компьютер.
- Целевая операционная система для первой проверки - Windows, если заказчик не согласует иное.

Эти пункты являются проектными предположениями, а не подтверждёнными требованиями заказчика. Их нужно согласовать до начала реализации.
