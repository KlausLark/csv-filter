## О проекте

CSV-фильтр - настольная утилита для загрузки табличных данных из CSV-файлов, отбора строк по условию и сохранения результата в новый файл.

Документ подготовлен по заданию «Разработка предпроектной документации и плана реализации». Он описывает цели и границы проекта, пользовательские истории, нефункциональные требования, архитектуру, план работ, оценку и риски.

## Предлагаемый стек

- Python 3
- Tkinter и ttk для графического интерфейса
- Стандартный модуль `csv` для чтения и записи
- `unittest` для тестирования
- Git для контроля версий
- GitHub для размещения репозитория

## Ожидаемый результат

Пользователь сможет открыть CSV-файл, выбрать столбец, оператор и значение, увидеть подходящие строки и сохранить их в отдельный CSV-файл. Исходный файл не изменяется автоматически.
